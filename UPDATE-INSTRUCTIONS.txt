V11 HOMEPAGE IMAGE FIX

Root cause fixed: server.py previously injected the SQLite-backed localStorage bridge only when an HTML file contained the exact string <head>. The V11 admin page uses <head><meta..., so admin settings were being saved only in that browser instead of the shared SQLite database. The bridge is now injected after any normal opening <head> tag.

Install safely:
1. Stop the running server with Ctrl+C.
2. From ~/Claude, back up the database:
   cp V11/saree_store.sqlite3 V11/saree_store.sqlite3.backup
3. Extract this ZIP into ~/Claude (the archive contains a V11/ folder):
   unzip -o ~/Downloads/V11-Homepage-Images-Fixed.zip -d ~/Claude
4. Start the app:
   cd ~/Claude/V11
   bash start.sh
5. Open http://127.0.0.1:8000/admin, sign in, open Homepage, and upload an image.
6. Refresh the customer homepage to confirm the hero/gallery image appears.

This ZIP intentionally excludes saree_store.sqlite3 and existing static/uploads images. Do not delete either from your current V11 folder.
